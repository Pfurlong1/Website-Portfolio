An eleven-week group game production which I led, directed and was actively a part of throughout the entire development process from scratch, creating a full multiplayer online Quake-style FPS shooter via Steam.

Procedural Generating Cave Systems

This project was created as part of my master's thesis, which consists of three different algorithms including Open Simplex Noise, Cellular Automata and Marching Cubes. These were developed using C++ and implemented inside Unreal Engine 5.4.4 in order to conduct a comparative analysis between the three.

Built using C++ and Unreal Engine's Blueprints
